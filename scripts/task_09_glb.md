Scene facts: armature object "Mascot_Rig" (deform bones only matter), empty "Mascot_Root" parents every character mesh (directly). Algorithm (put each step in a function):

3. For every source object build a low-poly baked-shape copy `make_lowpoly(src)`:
   a. remember its shape keys (if any) and DRIVERS: for each key block (except Basis) find the driver fcurve on src.data.shape_keys.animation_data (data path 'key_blocks["NAME"].value'); record (key_name, driver expression, list of variable names).
   b. morph name rule: if the expression with spaces removed equals a single variable name -> morph = that variable name (e.g. "blink_L", "m_laugh", "brow_raise_R").       Keep ONLY morphs in KEEP = {"blink_L","blink_R","eye_wide","squint_L","squint_R","lid_flat","pupil_big","pupil_small","look_right","look_left","look_up","look_down","brow_raise_L","brow_raise_R","brow_lower","brow_angry","brow_sad","m_small_smile","m_big_smile","m_laugh","m_O","m_flat","m_frown","m_smirk_L","m_smirk_R","m_shout","m_wail","m_teeth","m_tongue_out","v_A","v_E","v_I","v_O","v_U","v_MBP","v_FV"}.
