# Synergist Lubricants mascot, v2

A from-scratch rebuild of the plush oil-drum mascot in Blender 5.2. Version 1 is untouched in the parent folder.

## What is here

- `models/synergist-mascot-v2.glb`: the 3D model for web, phone and AR. 26k triangles, 48 bones, 45 face shapes (morph targets), about 2.7 MB. It opens in the waving pose.
- `media/turntable_v2.mp4`: 360 degree spin, 6 seconds, 1080 px.
- `renders/`: hero renders (1500 px), model sheet, the 20 expressions, the 20 stickers and their contact sheets.
- `renders/stickers/`: Telegram stickers, 512 px PNG and WEBP. `notext/` holds the same stickers without captions.
- `scripts/`: everything is generated by these Python scripts.

The 4K hero renders and the master `mascot_v2.blend` (full-detail model, rig, face shape keys, studio lights) are in `exports/` and `blend/` on KTPC, outside git.

## How the model is built

| Script | What it does |
| --- | --- |
| `m_util.py` | Proportions, colours and mesh helpers |
| `m_face.py` | The parametric embroidered face: 45 shapes and 20 expressions |
| `m_build.py` | Barrel, arms, gloves, shoes, logo patch, materials and the armature |
| `m_pose.py` | Posing: arms and legs follow curves like rubber hoses, hands and feet are placed directly |
| `m_props.py`, `stickers_data.py` | Sticker props, poses and captions |
| `r_expr.py`, `r_stickers.py`, `r_final.py` | Renders (expressions, stickers, heroes, turntable, master file) |
| `compose.py` | Sticker captions and outlines (headless Chrome, so Khmer shapes correctly) |
| `export_glb.py`, `check_glb.py` | GLB export and a re-import check |
| `finish.py` | Backgrounds, contact sheets, video and zip packages |

Run a Blender script with `blender -b --factory-startup --python scripts/<name>.py`. `prep_logo.py`, `compose.py`, `finish.py` and the sheet scripts use system Python with Pillow.

## Face shapes

Eyes: `blink_L/R`, `happy_L/R`, `eyes_wide`, `eyes_squint`, `lids_angry`, `lids_sad`, `lids_half`. Pupils: `look_left/right/up/down`, `pupil_small`, `pupil_big`. Brows: `brow_up_L/R`, `brow_down`, `brow_angry`, `brow_sad`. Mouth: `smile_closed`, `smile_big`, `mouth_o`, `frown`, `flat`, `smirk_L/R`, `shout`, `pout`, `wavy`, `tongue_out`, `grin`, `wail`. Visemes: `vis_A`, `vis_E`, `vis_I`, `vis_O`, `vis_U`, `vis_MBP`, `vis_FV`. Extras: `blush`, `fx_hearts`, `fx_stars`, `fx_tears`, `fx_sweat`.

The 20 expressions (Happy, Big laugh, Wink, Grateful, Excited, Love, Proud, Surprised, Shocked, Thinking, Confused, Shy, Embarrassed, Worried, Sad, Crying, Annoyed, Determined, Sleepy, Calm) are mixes of these shapes. In the master file, run the `apply_expression` text block to set one.

Reference images, fonts, logo textures, working files and `exports/` are kept out of git.
